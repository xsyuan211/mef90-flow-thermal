### 平台能力盘点（关键发现，有长期价值）

- `flow.source` 是 cell-set 体积源，量纲 [1/s]（由 `-div(A grad p) = f`, `A=k/mu` 推得），
  故总排量 `Q = ∫f dV`；`source_scaling: constant/linear/file` 支持排量斜坡、阶梯、
  从 EXO 逐时间步读变排量程序（Gate 4.7 的 File 律同机制）。
- `vDef/vDefHF.F90` 是上游**水力压裂专用主程序**：`CrackVolumeControlled` + secant 迭代
  反解 `CrackPressure` 使裂缝体积等于 `time(step)`，即 `dV/dt = Q` 的体积控制注入；
  `InjectedVolumeATol` 控容差；注释含 "Secant method for sneddon" 解析验证。
  **但当前 CI 只编译 `vDef`（Makefile 的 `vDefHF` 是独立 target，且只链接
  DefMech + HeatXfer，不含 `m_Flow`）**——要真正做压裂数值实验必须接线。
- 可压性参数齐全：`fracturetoughness` (Gc)、`internalLength` (ell)、`YoungsModulus` /
  `PoissonRatio`、`damage: AT2`、`toughnessAnisotropyMatrix`（2D 3 分量 / 3D 6 分量
  RealArray，**可直接表征页岩层理各向异性韧性**）、`plasticityType`、
  `drivingForceType` (Drucker-Prager，剪切起裂)、`unilateralContact`。
- 滤失/孔弹：`perm_min/perm_max`、`storativity`、`biot_coeff`；损伤–渗透率律为
  `k(v) = k_min + (k_max-k_min)*v`（deck 中 20× 增强），即裂缝导流代理。
- 目标量：damage 场、p、u、`InjectionWork`、elastic/surface/cohesive/forceWork 能量分解、
  `CrackVolume`；3D tetra4 网格已由 Gate 4.14（CI #121）验证可分派。
- 缺口：井筒/孔眼摩阻/多簇分流、支撑剂、地应力张量入口、DFN 离散天然裂缝、
  现场尺度、产能递减模型。

### 离线标度结论（本次真实计算）

1. **排量双通道解耦**：黏度主导 `p_net=(E'^2 mu'/t)^{1/3}` 与 Q 无关；韧性主导
   `p_net = K'/sqrt(L_k)` 随 Q 下降（0.041→0.024 MPa，Q 4→20）。同区间孔眼摩阻
   0.63→15.64 MPa、BHTP 50.93→65.94 MPa。⇒ 现场「大排量提净压」几乎全部来自
   完井限流，不是储层裂缝力学；Q 作为产能模型特征必须与孔数/孔径/簇数交互。
2. **无量纲韧性** `Kdim = K'/(E'^(3/4)(mu' q)^(1/4))`（q 为单位缝高排量，量纲已验证
   无量纲）随 Q 按 `Q^(-1/4)` 下降 ⇒ 加排量把系统推向黏度主导，不利于韧性控制的
   复杂缝网。四类页岩 𝓚 实测范围 0.146–1.194，均不进入韧性主导（𝓚>3）。
3. **滤失是强约束**：强滤失/天然裂缝发育类在 Q=20 时 `V_leak/V` 仍 0.60 > 0.5，
   单靠排量无法解决，必须降滤失/暂堵/提黏 ⇒ 「匹配」应定义为多约束可行窗口。
4. **尺度警示**：现 deck 的 `c_v = k/(mu S) = 108.7 m²/s` 是让 1 s 跑完固结的数值验证
   代理；真实页岩 k=1e-20~5e-18 m² 给 c_v=4.35e-9~2.17e-6 m²/s，差 8–10 量级，
   `t_inj/t_diff ~ 1e-9~1e-7`（施工期基质孔压扩散完全冻结）。
   ⇒ 现场问题必须靠**无量纲相似**（固定 `T = c_v t/H²`、𝓚、𝓛、`Pi_c`）在秒级数值
   实验复现小时级机制，不能直接照搬 51 步 1 s 的时间设置。

### 关键判断：原 R4 判据的物理前提是错的

- 核实 **Lecampion, Desroches, Jeffrey & Bunger (2017), JGR Solid Earth, doi:10.1002/2016JB013183** 全文：「Prior to fracture initiation, the flow rate entering the fracture Qin is negligible, which for a constant injection rate Q0 results in a linear pressurization rate. - **三处结构性不相容**：① M7 要求 T 单调角点包络 ≥4 decades（防收窄区间伪造精度），实测单点使跨度=0 ⇒ 区块 profile 会让 M7 FAIL，需要新判据 M7′；② S=5.99e-11 < 文献包络下界 1e-10；③ 语义/尺度错配：涪陵是**页岩气**而参数表是**陆相页岩油**（c_fluid、μ 不同）、DFIT 净压 ≠ C_L 反演压差、DFIT 测试层厚 ≠ 缝高、DFIT 泵注尺度 ≠ 主压裂尺度。
- **文献争议**：McClure et al. (URTeC 2019) 指出气页岩 DFIT 的「false radial」会大幅高估 k、Barree tangent 法低估闭合应力并高估净压；涪陵 A 井正是用拟径向流求 k、用 G 函数切线求净压，故 k=0.00152 mD 与 p_net=7.57 MPa **都可能偏高**。
- 结论：数值可得、可代入、可复算，但**没有任何单一公开数据集「完整满足」**；且即使凑齐，14.5 的物理限制不变（起裂前 β=f/S 线性无阈值 ⇒ 排量优选无定义）。若要落地需新增 `block_profiles` + M7′ 判据，并先裁定上述语义口径。该调研轮次**未创建任何版本库文件、未提交、未推送**。
