## CI #81 结果：第三次假收敛；新根因 = Split 导致 R/J 不一致（CI #82 已发起）

- **CI #81「KSPINIT CONVERGED」是假的**。`vDef.F90:573` 只在
  `snesDispConvergedReason < 0` 时打印失败消息，故 `rk_fail=0` 只代表返回非负原因。
  实际每步仅 3 次 Newton 迭代：`2.08e4 → 9.345 → 9.345`（重复，中间 KSP 0 迭代），
  153 条 fnorm 最小 6.26、最后 7.45，而容差 `atol=1e-7, rtol=1e-5` 对应阈值 ≈0.208。
  ⇒ 步长被压到 0，SNES 以 `SNES_CONVERGED_SNORM_RELATIVE` 静默假收敛，位移求解停滞。
  三次误判：#75 watcher 区间误读 / #78 崩溃假收敛 / #81 步长 0 假收敛。
  **教训：收敛判定必须基于 fnorm 降到容差，不能数失败消息。**
- **新根因（代码级）**：`m_MEF90_DefMechAssembly.F90` 残差 287–289 无条件
  `Split%DEED`（HydrostaticDeviatoric 谱分裂），雅可比 649–650 在 `cellIsElastic`
  时却用完整 `HookesLaw` ⇒ **J ≠ dR/du**，Newton 方向错 → 步长 0 → 残差卡在 O(8)。
  这统一解释了换遍 KSP/PC、关损伤、关 nonzero 初值均无效。
  且 Terzaghi 纯孔弹性基准本不该有 unilateralContact 分裂。
